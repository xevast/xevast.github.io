XEVAST ADS FOLDER (home page billboard)

ads/images/   put your ad PHOTOS here   (jpg, png, webp)
ads/videos/   put your ad VIDEOS here   (mp4 recommended)
ads/ads.js    write the file names here (open it in any text editor)

Steps
1. Copy your photo into ads/images/  (or your video into ads/videos/).
2. Open ads/ads.js and add the file name inside XEVAST_ADS_FILES, for example:  "ad1.jpg",  "promo.mp4",
3. Save and refresh the website. Done.

On GitHub: open the folder > Add file > Upload files > Commit. Then open ads/ads.js > pencil icon > add the name > Commit.

Notes
- Videos play muted with no controls and no timer.
- Use 16:9 size (1280x720). Keep files under 8 MB so the page stays fast.
