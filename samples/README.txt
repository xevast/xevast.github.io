XEVAST SAMPLES
==============
One folder per sub-service page. Put 1 to 5 sample files in a folder and they show up
on that service's page, in the "Sample work" section.

  samples/web-development/1.jpg ... 5.jpg
  samples/mobile-apps/1.png ...
  samples/cybersecurity/1.pdf ...

Allowed: jpg, jpeg, png, webp, pdf.   Names: 1, 2, 3, 4, 5.   Max: 5 per folder.
Run  python3 tools/check-samples.py  to see what is filled and what needs fixing.
Folder list: academy, academy-ai-automation, academy-cloud-devops, academy-cyber-fundamentals, academy-digital-marketing-seo, academy-ethical-hacking, academy-ui-ux-basics, academy-web-development, ai-solutions, cloud-devops, compliance-grc, custom-solutions, cybersecurity, data-analytics, forensics-ir, managed-it, mobile-apps, network-security, security-research-lab, seo-marketing, system-design, ui-ux-design, wams, web-development
