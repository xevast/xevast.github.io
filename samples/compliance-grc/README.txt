Samples for: Compliance & GRC
Shown on page: compliance-grc.html (section "Sample work")

HOW TO ADD SAMPLES
  1. Put 1 to 5 files in this folder, named 1, 2, 3, 4, 5:
       1.jpg  2.jpg  3.png  4.webp  5.pdf      (jpg, jpeg, png, webp or pdf)
  2. Upload the site again. They appear on the page automatically.
  3. Optional titles: edit js/samples-config.js (same order as the numbers).

TIPS
  - Maximum 5 samples are shown. Files 6 and above are ignored.
  - Images: 1600 x 1000 px (16:10) looks best. Keep each file under 1 MB.
  - Do not use real client names, data, keys or private details in a sample.
  - If this folder has no numbered files, the page shows "Samples are being added".
